# הכל להכל – ברטעה

موقع بالعبري (RTL) لزبون **جمال محاميد** + نظام مراسلة بين الزبون والمدير + لوحة تحكم للمدير.

## الأجزاء
| الصفحة | لمين | شو فيها |
|---|---|---|
| `index.html` | الزوار | الموقع + الأصناف + نموذج تواصل + **شات** + زر واتساب |
| `my.html` | الزوار | **"הפניות שלי"**: كل طلبات الزائر، الردود، إكمال المحادثة، عدد الرسائل الجديدة |
| `admin/` | المدير | **لوحة التحكم**: إحصائيات، الطلبات، الرد، وضع "טופלה"، حذف، واتساب/اتصال بالزبون، ردود سريعة، تعديل الرد التلقائي، تغيير كلمة السر |

## الرد التلقائي
بمجرد ما يبعت الزبون رسالة، بيوصله فوراً:
> שלום {name}, ותודה על הפנייה! 👋 כאן צוות הכל להכל – קיבלנו את ההודעה שלך ונחזור אליך בהקדם האפשרי. אם נוח לך, אפשר גם לדבר איתנו ישירות בוואטסאפ: {רابط واتساب}

المدير بيقدر يعدّله من: لوحة التحكم ← הגדרות.

## التشغيل على Hostinger (PHP 8 + SQLite – بدون قاعدة بيانات MySQL)
1. عدّل `api/config.php`:
   - `whatsapp` رقم الواتساب (مثال `972501234567`)
   - `setup_key` غيّره لنص عشوائي طويل (بيُطلب مرة وحدة عند إنشاء كلمة سر المدير)
   - `notify_email` (اختياري) إيميل يوصله إشعار بكل رسالة جديدة
2. عدّل `js/config.js` (رقم الواتساب، التلفون، الإيميل، ساعات العمل، الأصناف).
3. ارفع المجلد كله لـ `public_html`.
4. افتح `/admin/` ← أدخل `setup_key` ← اختر كلمة سر المدير.
5. تأكد إن `/data/hakol.sqlite` مش مفتوح من المتصفح (لازم يعطي 403). ملف `data/.htaccess` بيمنعه على Apache/LiteSpeed.

> إذا السيرفر ما اشتغل، نموذج التواصل بيعرض رابط واتساب للزبون كبديل.

## الحماية
كلمة سر مشفّرة (`password_hash`)، جلسة HttpOnly + SameSite=Strict، حماية CSRF، حد للرسائل لكل IP، honeypot ضد السبام، كل النصوص بتنعرض بشكل آمن (escape). روابط الزبائن سرّية (token عشوائي، ومخزّن مشفّر بـ sha256).

## ناقص من الزبون
- رقم الواتساب والهاتف والإيميل (حالياً أرقام وهمية).
- تأكيد الأصناف الفرعية (المقترحة حالياً أمثلة) + كتابة صنف "לפכפכינה".
- ساعات العمل، شعار، وصور منتجات إن وجدت.

## ملاحظة
"הפניות שלי" بتعتمد على المتصفح/الجهاز اللي بعت منه الزبون. إذا فتح من جهاز ثاني ما بيشوف المحادثة (بيقدر يتواصل بالواتساب).
