# הכל להכל – ברטעה

موقع ثابت (HTML/CSS/JS) بالعبري (RTL) لزبون **جمال محاميد**.

- **كل التعديلات من ملف واحد:** `js/config.js` (رقم الواتساب، الهاتف، الإيميل، ساعات العمل، الأصناف والأصناف الفرعية).
- **التواصل:** زر واتساب عائم + أزرار واتساب + نموذج تواصل.
  - إذا كان `formEndpoint` فارغاً: النموذج يفتح واتساب مع تفاصيل الطلب جاهزة.
  - لإرسال النموذج للإيميل: أنشئ نموذجاً مجانياً على formspree.io وضع الرابط في `formEndpoint`.
- كل صنف يفتح نافذة فيها الأصناف الفرعية؛ الضغط على صنف فرعي يفتح واتساب برسالة طلب سعر جاهزة.
- الرفع: انسخ المجلد كما هو لأي استضافة (Hostinger / Netlify / GitHub Pages).

## ناقص من الزبون
- رقم الواتساب والهاتف والإيميل (حالياً أرقام وهمية).
- تأكيد الأصناف الفرعية (المقترحة حالياً أمثلة).
- تأكيد كتابة صنف "לפכפכינה".
- شعار وصور منتجات إن وجدت.
