## ملاحظة تقنية
- `_elementor_data` قابل للتعديل عبر REST (`/wp/v2/pages/{id}` → `meta`).
- الـ HTML Blocks (`cms_block`) وخيارات Woodmart و"CSS إضافي" **غير متاحة عبر REST**؛ تحتاج لوحة التحكم أو إضافة.
- إعدادات Elementor العامة (`elementor_library/8` ← `_elementor_page_settings`) قابلة للتعديل عبر REST، لكن ملف CSS الخاص بها لا يتجدّد إلا بالحفظ من المحرّر أو بمسح الكاش الكامل (ممنوع، انظر أدناه).
- Elementor يخزّن نسخة من العناصر (element cache) لمدة 24 ساعة، فقد يتأخر ظهور تعديل النصوص.
- لا تمسح كاش Elementor بالكامل قبل استرجاع الصور: يمسح نسخ أيقونات SVG المخزّنة، وملفاتها مفقودة.
